## 現在のゲーム方針

TYPE TOWERは、タイピングしながら学習する3種類の塔を遊ぶブラウザゲームです。

### 学習対象

- **漢字の塔** — 日本語を学ぶ外国人向け。表示された漢字の読みをひらがなで入力する
- **英訳の塔** — 日本人向け英単語学習。日本語を見て英単語を入力する
- **和訳の塔** — 日本人向け英単語学習。英単語を見て日本語を入力する。漢字表記だけでなく**ひらがな回答も正解**として扱う

英訳・和訳は文章問題ではなく、基本的に**単語・語彙問題**として扱います。

## GAME SETTING

塔を選んだあと、GAMEへ入る前に設定画面を表示します。

### MODE

#### 通常

- 1Fから開始
- 正解で +1F
- MISSで -1F
- 1F未満には下がらない
- 9Fで正解すると10Fへ進む
- **10Fの問題を正解するとCLEAR**
- CLEARまたはTIME UPでRESULTへ進む

#### ENDLESS

- 10F CLEARでは終了しない
- 問題を解き続ける
- 正解数を画面へ表示する
- 制限時間がある場合は0秒でRESULTへ進む
- 無制限の場合も含め、`終了してRESULT` から手動終了できる

## LEVEL

時間の厳しさではなく、**出題する問題そのものの難しさ**を3段階に分けます。

- **Lv.1 基礎** — 初心者向けの基本語彙・基本漢字
- **Lv.2 標準** — 日常・学校学習で使う標準的な語彙
- **Lv.3 発展** — より難しい語彙・抽象語・読みづらい漢字

難易度とTIMEは別々に選べます。

## TIME

TIMEは問題ごとではなく、**ゲーム全体の制限時間**です。

選択肢:

- 60秒
- **90秒（初期設定）**
- 120秒
- 無制限

問題が変わっても残り時間はリセットしません。無制限ではTIME表示を `∞` にします。

## データ

現在のゲーム本体ではレベル付きデータを使用します。

### 漢字

`data/kanji-levels.json`

```text
question / answer / level
```

Lv.1〜Lv.3を**各150問**ずつ用意しています（合計450問）。

### 英訳・和訳

`data/english-words.json`

```text
ja / en / level
```

Lv.1〜Lv.3を**各150語**ずつ用意しています（合計450語）。英訳と和訳で同じデータを共有するため、両方の塔で各Level 150問を利用できます。

- 英訳 → `ja` を問題、`en` を答え
- 和訳 → `en` を問題、`ja` を答え

和訳用には `data/english-kana.json` も使用します。450語すべてにひらがなの正解表現を持ち、たとえば `book` に対して `本` だけでなく `ほん`、`school` に対して `学校` だけでなく `がっこう` でも正解になります。

必要な単語では複数の正解表現も登録できます。

旧 `ja-en.json` / `en-ja.json` は現在のGAMEでは読み込みませんが、すぐには削除せず残しています。

## 現在の画面Flow

```text
HOME
→ START
→ SELECT
→ 漢字 / 英訳 / 和訳から塔を選ぶ
→ GAME SETTING

→ 通常: 10F CLEAR または TIME UP

```

## コードの書き方

学校制作として読みやすいことを優先し、関数名・変数名は英語だけへ無理に統一しません。

例:

```js
function gameJunbi() {}
function mondaiLoad() {}
function tsugiNoMondai() {}
function seikaiSyori() {}
function timeHyouji() {}
```

英語と分かりやすいローマ字を自然に混ぜます。ただし既存参照を壊す名前変更は行わず、変更時はHTML / 他JSからの参照も一緒に確認します。

## STEP追加コードの基本ルール

1. ゲーム本体 `EliteMay/type-tower-a/main` の現在コードを正とする
2. 前STEPの実装を理由なく消さない
3. HTML / CSS / JavaScriptの既存参照を確認して変更する
4. 行番号より、実在するコードを目印にした位置案内を優先する
5. 現在本体へ直接反映済みの機能は、古い追加コード例より本体を優先する

## 最終テストで確認すること

- HOME → SELECT → SETTING → GAME → RESULTを最後まで通せる
- 3つの塔すべてで正しい問題が出る
- Lv.1 / 2 / 3で問題データが切り替わる
- 英訳で日本語→英単語の回答が正しく判定される
- 和訳で英単語→日本語を出題し、**漢字回答とひらがな回答の両方が正解になる**
- 60 / 90 / 120秒が正しく減る
- 無制限でTIME UPしない
- 通常モードで10Fの問題を正解するとCLEARする
- ENDLESSで10F相当まで正解しても終了しない
- ENDLESSを手動終了できる
- MISSしても1F未満へ下がらない
- RESULTの正解数 / MISS / 正答率 / TIMEが実プレイと一致する
- 再挑戦できる
- SELECTへ戻れる
- Enter連打で二重判定しない
- 主要画面で崩れ・はみ出し・押せないボタンがない

## 3人開発の基本方針

ゲームの中心部分は完全分業せず、3人で目的を確認し、1人がその時間の操作役になります。操作役は機能や時間ごとに交代します。

分担しやすいもの:

- 問題追加
- 問題調査
- ロゴ・背景・塔・敵などの素材準備
- テスト
- 動画素材

GitHubでは人別ではなく作業内容ごとにBranchを分け、同じファイルを別々に同時編集しないことを優先します。
