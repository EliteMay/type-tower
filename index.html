01 / BACKGROUND

背景は自分たちの素材を使う

現在用意している背景動画を最背面でループさせます。方針サイト側では背景素材そのものの見た目を決めません。

02 / TOWERS

3つの塔を同時に見せる

漢字・英訳・和訳を3つの塔として横並びにします。塔画像は自分たちで用意し、同じ高さの基準線に揃えます。

03 / LABEL

塔名は塔の下、ボタンの上

塔画像の中へ文字を焼き込まず、塔名を別のUIとして置きます。素材を差し替えても位置関係を保ちやすくします。

04 / BUTTON

各塔の下に開始ボタン

どの塔を選ぶか迷わないように、塔名のすぐ下に同じ形の開始ボタンを置きます。

STEP Aサイトを開く

背景と3つの塔が最初から表示される。

STEP B塔を選ぶ

漢字・英訳・和訳のどれかを選ぶ。

STEP C選択を保存

押した塔のモードをゲーム側へ渡す。

STEP Dゲーム開始

1Fから最初の問題を表示して開始する。

見た目の優先順位：背景動画と塔素材を主役にし、塔名・開始ボタンは見やすく整える。まだ作っていないGAME画面やRESULT画面の見た目は、今の段階では先回りして作り込みません。

BUILD ORDER

この順番で作る

このページでは目的と完了条件だけ確認します。実際に書く内容が必要になったら「コード全文」ページを開きます。

1
HOME

3画面の箱 + HOMEの3つの塔

最初

HOME・GAME・RESULTの3画面を用意し、HOMEには3つの塔を並べる。

作るもの
  • 背景動画
  • 3つの塔を置く場所
  • 塔名と開始ボタン
完了条件
  • 開いた瞬間に3つの塔が見える
  • 漢字の塔からGAMEへ進める
  • 他の2塔も見た目は置けている
2
DATA

漢字問題を表示する

最初は漢字の塔だけで問題データの読み込みと表示を完成させる。

作るもの
  • 漢字問題データ
  • 問題のランダム表示
  • 答えデータ
完了条件
  • GAME画面に問題が1問出る
  • 別の問題へ切り替えられる
  • 最低10問で確認できる
3
CORE

タイピング判定を完成させる

入力、確定、正解・MISS、次の問題までを連続して遊べる状態にする。

作るもの
  • 回答入力欄
  • 正解判定
  • MISS判定
完了条件
  • 正しい答えで正解になる
  • 違う答えでMISSになる
  • 続けて次の問題へ進める
4
FLOOR

正解 +1F / MISS -1F

現在階を管理し、正解・MISSと塔の上下をゲームルールとしてつなぐ。

作るもの
  • 現在階
  • 階数表示
  • 10Fクリア
完了条件
  • 正解で1階上がる
  • MISSで1階下がる
  • 1F未満にならない
  • 10Fでクリアになる
5
LOOP

漢字の塔を最後まで遊べる状態にする

見た目を増やす前に、塔選択からRESULTまでゲームの一本線を完成させる。

確認する流れ
  • HOMEから開始
  • 問題に回答
  • 10Fへ到達
  • RESULTへ進む
完了条件
  • 最初から最後まで止まらない
  • 再挑戦できる
  • 塔選択へ戻れる
6
RULES

TIME / COMBO / 難易度

完成したゲームループを壊さないよう、追加要素を1つずつ入れる。

追加するもの
  • 制限時間
  • コンボ
  • 難易度
完了条件
  • 時間切れでMISSになる
  • コンボが正しく増減する
  • 難易度変更が反映される
7
MODES

英訳・和訳の塔をつなぐ

漢字で完成した仕組みを使い、残り2モードへ広げる。

追加するもの

  • 和訳問題
  • 塔ごとの問題切替
完了条件
  • 3つの塔すべてから開始できる
  • 塔ごとに問題が違う
  • 3モードとも最後まで遊べる
8
RESULT

RESULTと記録保存

プレイ結果を分かりやすく見せ、再読み込み後も記録が残る状態にする。

表示するもの

  • 最大コンボ
  • クリア時間

  • 実プレイと数字が合う
  • 記録が保存される
  • 保存失敗でもゲーム自体は遊べる

  • 正解・MISSの移動方向が自然
  • 主要UIが重ならない

  • 戻る・再挑戦

TEAM WORK

基本は3人で一緒に作る

ゲームの中心部分は完全分業せず、3人で同じ目的を確認してから1人が操作役になります。操作役は交代します。

基本

ゲームの中心は一緒に

画面切替、判定、階数、タイマー、ゲームの流れ、重大バグは3人で確認しながら進める。

交代

操作役を固定しない

1人だけがずっと書く形にせず、機能や時間ごとに操作役を交代する。

分担OK

独立した単純作業

問題追加、問題調査、ロゴ案、素材探し、テスト、動画素材などは並行して進めてよい。

GitHubの分け方

人ごとに作業場所を固定するのではなく、タイピング機能、問題追加、RESULTなど、作業内容ごとに分けます。同じファイルを別々に同時編集しないことを優先します。

DONE DEFINITION

完成条件

「一部が動く」ではなく、3人が最初から最後まで安定して遊べる状態を完成とします。

3つの塔

漢字・英訳・和訳の3つすべてからゲームを始められる。

ゲームループ

問題表示、入力、判定、階数変化、10Fクリア、RESULTまで止まらない。

ルール

正解、MISS、TIME、COMBO、難易度が想定どおり動く。

記録

RESULTの数値が実プレイと合い、必要な記録が残る。

見た目

背景や塔素材を入れても問題文・入力・ボタンが読みやすい。

最終確認

3人が通しプレイし、進行不能の重大バグが残っていない。
