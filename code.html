HOW TO WRITE

「何行目 + このコードの後ろ」で探す

行番号だけだとコード追加後にずれるため、必ず本体に実在するコードを目印として併記します。

① 途中に追加する場合

例：`js/game.js 約56行目`、`async function handleCorrect(){` の直後。という形で表示します。

② ファイル末尾に追加する場合

例：`js/main.js の末尾（現在約25行目以降）`、最後の `showScreen('select');` の後ろ。という形で表示します。

③ 一部だけ置換する場合

対象の行や関数名を指定し、その部分だけ置換します。ファイル全文は置き換えません。

行番号がずれたら目印コードを優先

本体へ前のSTEPを追加すると行番号は変わります。その場合は、表示された関数名・既存コード・HTML要素を探して追加してください。
