HOW TO WRITE

コードの追加場所は3種類だけ

「どこへ書くか」を毎回STEP内に表示します。特に記載がなければ、基本はそのファイルの一番後ろへ追加します。

① 末尾に追加

CSSの新しいルール、新しいJavaScript関数など。既存コードの最後にそのまま書き足します。

② 途中に追加

HTMLの特定要素の中、既存関数の中など。STEPに「この行の直後」「この要素の中」と場所を明記します。

③ 一部だけ置換

既存処理そのものを変える必要がある場合だけ使います。ファイル全文ではなく、対象の関数や1ブロックだけを変更します。
