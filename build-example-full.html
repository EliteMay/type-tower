HOME UI DECISION

タイトル・ロゴ・塔名はこの位置にする

背景動画と塔素材を主役にしたまま、文字が素材へかぶらず、どのボタンがどの塔か一目で分かる配置にします。

配置の決定

ロゴ + TYPE TOWERタイトル：画面上部中央に横並び。3つの塔とは別グループにして、ゲーム名を最初に認識できるようにします。

3つの塔：画面の中央〜下側。背景動画を隠しすぎず、開始ボタンまで同じ視線の流れで見える位置にします。

塔の名前：塔画像の真下、開始ボタンの真上。塔画像の中へ文字を入れないので、自分たちで用意した塔素材を差し替えても文字位置が崩れにくくなります。

上部中央：ロゴ + TYPE TOWER 中央〜下：3つの塔 各塔の下：塔名 塔名の下：挑戦ボタン

ロゴについて

ロゴ画像にすでに「TYPE TOWER」の文字まで入っている場合は、タイトルを二重表示しないように <h1 class="select-title"> を外してロゴだけにしてもOKです。ロゴがまだ未完成なら、先にタイトルだけ置いて後から画像を追加できます。
